# Web Application Basics

A web application mainly has **3 parts**:

```text
Frontend → Backend → Database
```

## 1. Frontend

The **frontend** is what the user sees and interacts with.

Examples:

* HTML
* CSS
* JavaScript
* React
* Vue.js

```text
User → Frontend
```

Example: Login form, buttons, dashboard.

---

## 2. Backend

The **backend** processes requests and contains the application's logic.

Examples:

* Node.js / Express
* Python / Django
* Java / Spring Boot
* C# / ASP.NET

The frontend communicates with the backend through an **API** using HTTP/HTTPS.

```text
Frontend → API → Backend
```

---

## 3. Database

The **database** stores application data.

Examples:

* PostgreSQL
* MySQL
* MongoDB
* SQL Server

```text
Backend → Database
```

The frontend normally does **not** connect directly to the database.

---

# Beginner Login Example

User enters:

```text
Email: rakib@gmail.com
Password: 123456
```

Then:

```text
User
 ↓
Frontend
 ↓
POST /api/login
 ↓
Backend
 ↓
Database
 ↓
Backend
 ↓
Frontend
 ↓
Dashboard
```

The backend checks whether the user's credentials are valid and sends the result back.

---

# Easy Memory

```text
Frontend = SHOW
Backend  = PROCESS
Database = STORE
```

### Complete Flow

```text
User → Frontend → API → Backend → Database
                              ↓
User ← Frontend ← API ← Backend
```

**Exam Definition:**
A web application consists of a frontend for user interaction, a backend for processing and business logic, and a database for storing data.
